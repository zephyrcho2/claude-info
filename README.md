# claude-info

Claude Code를 쓰면서 알게 된 팁, 설정, 명령어를 정리해 두는 개인 저장소.

## 문서

- [claude-info.md](claude-info.md): 본문. 명령어마다 기능, 용도, 사용법을 정리한다.
- [CLAUDE.md](CLAUDE.md): 이 저장소에서 Claude Code가 따르는 작성 규칙.

## 정리 방식

새로 쓰게 된 명령어나 팁을 Claude Code 세션에서 알려 주면, Claude가 공식 문서([code.claude.com/docs](https://code.claude.com/docs))를 확인해 `claude-info.md`에 덧붙인다.
